# Fonts served with Polynet

- `excalifont.woff2`: Excalifont, the hand-drawn face from Excalidraw
  (https://github.com/excalidraw/excalidraw, "Excalifont"), released under the
  SIL Open Font License 1.1 (https://openfontlicense.org). Community themes use it
  as a display face (`font_heading: "Excalifont"`).
